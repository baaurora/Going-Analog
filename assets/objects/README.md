# Object cutouts

Drop the generated PNGs here, then add them to the `OBJECTS` array at the top of
`assets/js/site.js`. Nothing renders until that array has entries, so missing
files never show as broken images.

Expected filenames (see docs/BRAND-BRIEF.md section 04 for the prompts):

    A1-polaroid-camera.png    A5-photo-booth-strip.png   A9-locking-pouch.png
    A2-disposable-camera.png  A6-flash-bulb.png          A10-masking-tape.png
    A3-film-canister.png      A7-phone-jail-box.png      A11-binder-clip.png
    A4-negative-strip.png     A8-dead-smartphone.png     A12-blank-polaroid.png

Requirements: true transparent background, square, at least 1000px.
